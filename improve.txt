The hard constraint

A WebSocket cannot survive a document unload. The browser destroys it. No API changes that — not SPA tricks, not View Transitions, not Speculation Rules. Those make the paint smooth; JS state still dies. And you can't force a merchant's theme into SPA navigation from an app embed.

So the question isn't "keep the socket open." It's "what survives on the server while the browser rebuilds
itself."
